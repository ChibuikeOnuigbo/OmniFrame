# Original motion-design proof

`word-stagger.mp4` is an original two-word motion study using staggered text clips, back/ease curves, opacity and light/chromatic styling, authored through existing universal tools. It is inspired by the observed word-level timeline grammar in the supplied short; it is not a source-accurate recreation of that short or the RDT clip.

`kinetic-word-stack.mp4` is a second original study after downloading the actual 27-second Drive reference. Five staggered word clips use position/rotation/opacity curves, a real nested group and gentle group motion over shared particles. It is 4.5 seconds, 540×960, 24 fps, 108 decoded changing frames and silent. Its preview, timeline, manifest and tool trace are siblings. It is not a full 27-second reference remake, exact font/effect reconstruction or 3D-camera implementation.
