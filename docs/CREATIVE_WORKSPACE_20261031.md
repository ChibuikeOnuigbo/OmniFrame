## Scope and unfinished requirements

Raster deformation UI currently targets ordinary image/video clips; text/compound deformation, rigged or parent-aware on-canvas geometry editing, selection-limited liquify, mesh/cage transforms, stroke-local restore, deformation animation keys and GPU acceleration remain work. CPU raster preview quality follows the preview budget; 4K realtime performance is not established.
