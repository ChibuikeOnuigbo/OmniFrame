channels, numbered lesson series, mask/keyframe guides, and the official
CapCut resources), using **video titles as the feature index** — each title
was then cross-checked against feature write-ups on Google-indexed guide
pages (CapCut resources, mask-keyframe guides, editor reviews). Entries are
title-derived: they catalog what the tutorials teach, they are not
transcripts of watched footage.

**Partial** = core exists, depth gap noted · **Gap** = not present, logged

## What this pass implemented from the scan

- **In/Out range export** (rows 1-2, from the linked GraphixGrove video
  "Export Selected Clip in CapCut PC Without Cutting"): I/O keys mark the
  range, the timeline greys outside it, Export records only the slice, and
  a Cancel chip clears it (clearing matters — a forgotten range would
  silently shrink every later export).
- **Video Mask View** (rows 7, 24-34): split (infinite rotatable line +
  flip H/V/side), rectangle/ellipse, custom straight/curved shapes, and
  text masks with uploaded fonts, all Include/Exclude, with keyframed
  windows and easing curves.
- **Compound depth** (rows 3-6, 106-108): exact rebase math (a clip at
  2:00 lands at 0:00 inside; gaps preserved as black space), trimmed
  parents show hatched cut voids inside the nested timeline.
- **Docker customization** (rows 42, 92-95): Settings → Dockers shows the
  active mode and lets the user toggle left-rail panels and right-panel
  sub-tools; masking/patching/rotoscoping live as icons on the right dock.
