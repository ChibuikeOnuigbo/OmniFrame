# yt_hancy — hancy_explantion

Full explanation pack for **Hancybox (@Hancybox)** YouTube channel: every video
listed from the channel's Shorts and Videos tabs (first render page of each via
the r.jina.ai proxy, 2026-10-23), with a short description of what each video is
about and the Alight Motion (or CapCut / LumaFusion / AI) tools & features used
in it. 79 entries listed (48 shorts + 31 long-form); the channel reports 123
videos total — the remainder sit behind YouTube's infinite scroll and cannot be
reached from this sandbox. Requested cap was 1000; nothing is invented to fill
space.

Files (same data, seven formats):
- hancy_explantion.md    — markdown tables
- hancy_explantion.html  — styled browsable tables
- hancy_explantion.csv   — spreadsheet import
- hancy_explantion.xlsx  — Excel workbook (frozen header, wrapped cells, notes sheet)
- hancy_explantion.docx  — Word document
- hancy_explantion.pdf   — printable landscape A4
- hancy_explantion.json  — machine-readable source of truth

Evidence grades per row (column "evidence"):
- rewatch on saved contact sheet (youtube-audit/evidence/micro/<id>.jpg) + channel metadata
- per-short metadata page via proxy (publish date / description / likes)
- channel listing via proxy (title / tags / views)

Honesty: video frames and audio cannot be downloaded in this sandbox (YouTube
401 wall). Tool columns are observed on contact sheets where rewatched,
confirmed by each video's own description where fetched, otherwise mapped from
the video's own title/tags (his titles name the technique) — the evidence
column says which. AI-only videos are logged, never implemented in OmniFrame.
