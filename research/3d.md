# 3D, baking, lighting, environments, animation and rigging

**Checked:** 2026-09-18. Sources: Three.js, React Three Fiber/Drei, glTF, KTX2/Draco/meshoptimizer, RoomEnvironment/PMREM/RGBELoader, react-three-lightmap, three-gpu-baker, xatlas, PBRT, Blender manuals, FABRIK/three-ik/Fullik.

## Scene representation

`Scene3D` is serialisable and renderer-neutral. It stores objects, materials, environment, active camera, lightmap records, quality, texture limit and shadow quality. It does not store Three.js object instances.

GLB/glTF is primary because it carries meshes, PBR materials, skins, cameras and animation clips. OBJ is a constrained import path; it does not magically provide a rig or material graph.

## Environment modes

- `room`: deterministic procedural RoomEnvironment converted to PMREM;
- `hdri`: explicit HDR asset, PMREM-converted;
- `color`: flat environment for low-cost preview;
- `none`: no environment illumination.

Visible background and illumination can be decoupled. Rotation/intensity are scene properties, not hidden constants.

## Baking

The reference CPU baker is real: UV rasterisation, BVH visibility, shadow-tested direct lights, environment, diffuse bounce recursion, AO, à-trous denoise, padding and cache hash. It deliberately rejects the marketing shortcut of assigning a colour and calling it “baked”.

Unsupported/limited areas are documented:

- specular/refraction transport is not a v1 CPU bake target;
- animated geometry invalidates a static bake;
- alpha cutouts/normal-map transport need explicit handling;
- production GPU/native baking is a separate backend with the same scene/cache contract.

## Rigging and animation

- glTF skeletons preserve inverse bind matrices;
- linear blend skinning is the baseline;
- FABRIK is the stable interactive IK solver;
- CCD is available for quick posing;
- ball/hinge limits are explicit;
- imported animation clips are listed, sampled, looped, trimmed and blended;
- tracked points drive a 2.5D anchor or bone target only when a coordinate-space conversion exists.

A 2D track is not advertised as a metric 3D solve. The editor offers an honest 2.5D mode before full camera reconstruction.
