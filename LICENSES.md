# Licence policy

OmniFrame core is MIT unless a file states otherwise. This file is a policy and audit index, not a substitute for the licence text of third-party packages.

Preferred code licences: MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC. Every model stores separate implementation and weight licences. AGPL, CC-BY-NC and unknown weights are research-only until a legal review changes the decision.

See:

- `MODEL_REGISTRY.md` for model decisions;
- `THIRD_PARTY_NOTICES.md` for current package notices;
- `CREDITS.md` for attribution;
- `research/references.json` for source/reuse/reference classification;
- `scripts/license-audit.mjs` for the automated dependency check.
