## 3. Repo scan: cookies, secret keys, tokens, bots, connected files

Commands run (repo-wide, excluding `.git/` and `node_modules/`):
```bash
find . \( -name '.env*' -o -name '*.pem' -o -name '*.key' -o -name '*cookie*' -o -name '*credential*' -o -name '*secret*' -o -name '*.p12' -o -name '*.pfx' -o -name 'id_rsa*' -o -name '*.token' \)
grep -rInE '(BEGIN (RSA|EC|OPENSSH|PGP) PRIVATE KEY|AKIA[0-9A-Z]{16}|sk-[A-Za-z0-9]{20,}|xox[baprs]-...|ghp_[A-Za-z0-9]{36}|github_pat_...|AIza[0-9A-Za-z_-]{35})'
grep -rIl '__Secure-1PSID'   # cookie-value scan
grep -rohE 'secrets\.[A-Z_0-9]+' .github/workflows
```

Findings (honest, complete):
1. **No cookie VALUES in the repo.** The only cookie-related file is `youtube-audit/runner/errors/cookies-status.txt`, a *status summary* (key names + `present` flags, 3051-byte cookie file described but NOT stored). The actual YouTube cookies live only in the owner-managed GitHub secret `secrets.YT_COOKIES`, referenced by `.github/workflows/video-audit.yml` (line 83 merely iterates cookie *names* to validate the secret at run time).
2. **No private keys / cloud tokens / API keys.** The single grep hit is a false positive: a base64 PNG data-URI inside `test_ans_result/board_S_rdt_remake.json` (image bytes, not a credential).
3. **No `.env`, `.pem`, `.key`, `.p12`, `.pfx`, `id_rsa*`, `*.token` files** anywhere outside `.git/`/`node_modules/`.
4. **`.git/config` holds no credentials** (keys present: bare, email, fetch, filemode, logallrefupdates, merge, name, remote, repositoryformatversion, url); GitHub auth is injected by the Arena sandbox environment, and credential paths are excluded from snapshots.
5. **Bots / automation present (all repo-local, none credential-storing):**

   - MCP server `tools/mcp/tools.mjs` ( OmniFrame's own tool surface ).
