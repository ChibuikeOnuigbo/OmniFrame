# tutorial.md — 1,000 Text-Tutorial Titles Across Every Editor

A working index of text-focused video-editing tutorial topics: 20 editors × 50
text techniques = 1,000 titles, written the way they appear on YouTube.

**Honesty note:** these are tutorial *topics/titles* (the demand map), not
1,000 watched videos. The two source tutorials actually studied end-to-end
(transcripts read in full, techniques rebuilt) are the Alight Motion retro
text and CapCut watermark tutorials — see `docs/RETRO-WATERMARK-STUDY.md`.

## How to read this file

- ✅ = already recreated in OmniFrame as a **procedural text preset** — open
  the app → Text panel → *Text Preset Library*, type ANY text, click it.
  Test renders for vetting live in `testing_asset_etc/` (see its README).
- Blank status = queued. When you mark packs perfect/horrible in
  `testing_asset_etc/README.md`, approved looks become vetted defaults and
  the next techniques from this list get built.

## The character-count rule (applies to every preset)

Presets are procedures, not recordings of one word: stagger/settle/wave key
off each letter's normalized position `u = i/(n−1)`, so 2-letter and
16-letter texts run the same animation shape. Nothing forces the tutorial's
character count; each preset declares a sweet spot and the UI says so live
(e.g. "Best with 4–10 characters — yours has 2; it still maps").
