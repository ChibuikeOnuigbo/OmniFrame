Adobe After Effects — every tool & feature explained (from Adobe docs)

Source: helpx.adobe.com/after-effects (effects & animation presets overview + doc tree) · harvested 2026-10-23 · explains every tool/feature listed with what it does.

Compositions & project

  • Composition — timed canvas of layers with its own size/fps/duration
  • Precompose / nesting — collapse layers into a sub-comp to reuse & isolate transforms
  • Composition Profiler — per-layer performance readout
  • Comp settings / 3D renderer — Classic 3D, Advanced 3D, Cinema 4D renderer choice
  • Scene Edit Detection — auto-splits footage at detected cuts
  • XMP metadata — footage metadata read/write

Layers

  • Layer properties — anchor point, position, scale, rotation, opacity + per-property keyframes
  • 3D layers — per-layer depth, orientation, material options
  • Blending modes & layer styles — add/multiply/screen/overlay stacks + drop shadow/bevel styles
  • Camera layer, lights, point of interest — virtual camera rig with DOF + lights aimed by POI
  • Layer & comp markers — timed annotations for sync
  • Adjustment layer — effect carrier over everything below

Masks, mattes, roto

  • Masks (bezier paths + feather + expansion) — shape cut-outs on any layer
  • Track mattes (alpha/luma) — one layer's alpha/luminance cuts another
  • Roto Brush + Refine Matte — stroke-based foreground/background segmentation over time
  • AI-powered Object Matte — one-click subject matte
  • Content-Aware Fill panel — remove objects with temporal fill

Text

  • Text layers + Character/Paragraph panels — type tools with full typography control
  • Text animators (range selectors) — per-character position/scale/opacity animation
  • Text effects & presets — ready-made type-on/reveal looks
  • Variable Font Axes — animate weight/width axes as properties
  • Essential Properties / MoGraph templates — expose controls for Premiere; responsive design rules

Shapes & paint

  • Shape layers (paths, fills, strokes) — vector parametric or freehand paths
  • Shape attributes / paint & path ops — trim paths, merge paths, repeater, zig zag, offset paths
  • Taper shape strokes — stroke width ramps along path
  • Paint tools: Brush, Clone Stamp, Eraser — frame-by-frame raster paint strokes
  • Null controllers (Create Nulls From Path) — null per path point for rigging

Animation

  • Keyframes + Graph Editor (value/speed graphs) — easing curves, influence handles
  • Puppet tools (pin, bend, depth) — mesh-warp character animation
  • Shape path & mask interpolation — morph between path states
  • Roving keyframes, proportional scrubbing, wiggler — time & space tweaks
  • Expressions + data-driven animation — code-driven properties, JSON/CSV driven comps
  • Motion sketch / smooth / wander — capture hand-drawn motion paths

Effects & presets (categories)

  • Blur & Sharpen — Gaussian/camera/radial blur, unsharp, smart blur
  • Channel — invert, set matte, channel remap, blend
  • Color Correction — Lumetri-style wheels, curves, levels, vibrance, LUT
  • Distort — warp, bulge, twirl, turbulence, displacement
  • Generate — fills, gradients, beams, scribble, advanced lightning
  • Noise & Grain — add/remove grain, dust, median
  • Perspective — 3D glasses, drop shadow, radial shadow, bevel
  • Stylize — glow, mosaic, posterize, threshold, color emboss
  • Simulation/Transition/Utility — particle plays, block dissolve, linear/radial wipe, grow bounds
  • Animation presets — hundreds of shipped keyframe+effect combos

3D & render

  • 3D model import (glTF etc.) + C4D renderer — real geometry inside comps
  • Render queue / Adobe Media Encoder — templates, proxies, multi-machine renders
