Deep-scan notes

  • Freehand Brush: smoothing family = None / Basic / Weighted (Distance, Stroke Ending, Smooth Pressure, Scalable Distance) / Stabilizer (Sample Count at Max/Min Speed, Delay dead-zone for sharp corners, Finish Line, Stabilize sensors, Pixel mode for 1px lines). Assistants snapping slider 0-1000 + Snap Single + Snap Eraser. → OmniFrame backlog: stroke smoothing/stabilizer params.
  • Multibrush: modes Symmetry (count slider = our radialCopies), Mirror (X / Y / both = our new mirrorX/mirrorY), Translate (radius ring), Snowflake (mirrored symmetry), Copy Translate (placed copies), Copy Translate at Interval (X/Y grid, max 50). Axis defaults to canvas centre. → shipped: symmetry + mirror; backlog: translate/snowflake/copy-translate.
  • Gradient Tool: shapes Linear, Bilinear, Radial, Square, Conical, Conical-symmetric, Spiral, Reverse Spiral, Shaped; Repeat None/Forward/Alternating; Antialias threshold; Reverse; Dither (blue-noise for 8-bit). → shipped: linear + radial (gradientShape); backlog: remaining shapes + repeat modes.
