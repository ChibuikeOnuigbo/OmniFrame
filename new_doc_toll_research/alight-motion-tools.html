Alight Motion — full effects catalog + core tools (from official guide)

Source: guide.alightmotion.com/effects · harvested 2026-10-23 · explains every tool/feature listed with what it does.

Core tools

  • Layers (video/image/color/shape/text/null) — stackable timeline layers
  • Keyframes + graphs — easing curves per property (his 'graphs tutorial')
  • Parenting + null objects — group control rigs (null control short)
  • Camera & 3D layers — depth, camera moves, raster extrude looks
  • Text tools + presets — type-on, per-char animation
  • Shape layers + path morph — parametric shapes, morph transitions
  • Blending modes & masks — composite + feathered cut-outs
  • Transitions & speed (time remap/reverse) — clip-level timing tools

Blur & focus

  • Gaussian Blur / Box Blur / Precise Box Blur — soften at 3 quality levels
  • Lens Blur — depth-style bokeh blur
  • Directional Blur / Motion Blur — angle blur / sample-based motion blur
  • Inner Blur / Mask Blur — blur inside masks only
  • Magnify Background — enlarged blurred copy behind subject

Glow & light

  • Glow / Dark Glow / Light Glow / Inner Glow / Edge Glow — five glow flavours
  • Lens Flare / Rays / Radial Rays / Linear Streaks — light stings
  • Glow Scan — scanning glow line
  • Electric Edges / Lightning — energy outlines & bolts
  • Iridescence — oil-slick colour shift
  • Long Shadow / Radial Shadow — flat-design shadows

Colour

  • Brightness/Contrast, Exposure/Gamma, Highlights and Shadows — tone controls
  • Color Temperature / Color Tune / Colorize / Hue Shift — tint & remap
  • Gradient Map / Palette Map — ramp & palette remapping
  • Channel Remap (RGB/HSV), Invert, Hot Color, Posterize — channel ops
  • CMYK/Halftone Dots / Halftone Lines / Dots — print looks

Keys & mattes

  • Chroma Key / Luma Key — colour & luminance keying
  • Matte Choker — clean key edges
  • Copy Background / Fill Behind — backfill under transparency
  • Feather — soft layer edges

Distort & warp

  • Pinch/Bulge + Inner Pinch/Bulge — lens dome in/out
  • Bend / Curl / Fractal Warp / Random Displacement / Displacement Map / Polar Displacement Map — warp family
  • Glass / Omino Glass — refraction panels
  • Polar Coordinates — rect<->polar swaps
  • Mirror / Kaleidoscope — reflection symmetry

Repeat & pattern

  • Linear Repeat / Radial Repeat / Grid Repeat / Repeat / Repeat Along Path — copy arrays incl. path follow
  • Hexagon Array/Tiling/Tile Rotate/Tile Shift, Checker, Grid, Box, Hollow Box — pattern generators
  • Clouds / Noise / Fractal Ridges — procedural textures
  • Contour Gradient/Lines/Strips — topo-map looks

3D shapes

  • Cube / Cylinder / Ellipsoid / Pyramid / Octahedron / Hexagonal Prism — primitive 3D layers
  • 360º Reorient Sphere / 360º Viewer — VR handling

Motion & time

  • Auto-Shake — procedural shake
  • Echo Keyframes — motion trail ghosts
  • Oscillate — looping sine wobble on any property
  • Move Along Path / Repeat Along Path — path motion
  • Motion Blur, Flicker, Blink, Pulse Opacity, Pulse Size — time textures
  • Drawing Progress — stroke reveal
  • Count Up/Down — number counter
  • Fade In/Out — opacity ramps

Stylize & transition-ish

  • Mosaic / Pixelate — censor blocks
  • RGB Split — chromatic aberration
  • Dissolve / Block Dissolve / Radial Wipe / Flip Layer — in-layer transitions
  • Gradient Overlay / Four-color Gradient / Fill Behind — backdrops
  • Bump Map — relief from luminance
  • Linear Streaks / Radial Rays — speed looks
  • Raster Extrude — layer-copy 3D extrusion (his phonk look)
