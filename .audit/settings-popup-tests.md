# Settings popup evidence

One header Settings icon opens one compact fixed dialog. Actual Chromium checks passed for four categories containing only implemented behavior: Timeline, Playback, Shortcuts, and Accessibility.

Verified: open, category switch, project-FPS change, real Low/Medium/High preview backing-resolution and rendering-profile changes, reduced-motion class change, Escape close, and ownership of `H` while Settings is active. Ultra was deliberately removed; Low is visibly pixelated, Medium only slightly soft, and High adds a modest clarity increase. Timeline zoom was deliberately removed from Settings; zoom remains next to the timeline where its effect is visible. Existing context evidence also verifies popup/native ownership and responsive menu bounds.

Categories without real controls (General, Playback, Appearance, Performance, Import & Export) are intentionally absent rather than populated with placeholders. Native desktop behavior is SKIPPED.
