# Settings popup evidence

One header Settings icon opens one compact fixed dialog. Actual Chromium checks passed for three categories containing only implemented behavior: Timeline, Shortcuts, and Accessibility.

Verified: open, category switch, project-FPS change, reduced-motion class change, Escape close, and ownership of `H` while Settings is active. Existing context evidence also verifies popup/native ownership and responsive menu bounds.

Categories without real controls (General, Playback, Appearance, Performance, Import & Export) are intentionally absent rather than populated with placeholders. Native desktop behavior is SKIPPED.
