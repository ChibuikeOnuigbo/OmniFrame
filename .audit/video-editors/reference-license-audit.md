# Reference license audit

The exact license-file paths are captured in `clone-results.tsv`. This audit is a reuse boundary, not legal advice.

- MIT-reported references (OpenCut, OpenCut Classic, OpenReel, Clypra) were used only for behavioral/source-architecture comparison.
- GPL-family references (Kdenlive, Shotcut, Olive, LosslessCut, OpenShot, Flowblade, Natron, VidCutter, SynthCut) are reference-only. No code or assets were copied.
- Pitivi and Cinelerra-GG expose COPYING files and remain reference-only pending a dependency-level legal review.
- AI Video Editor, Free React Video Editor, Remotion, and React Browser Video Editor expose license files at their audited commits; no code was reused.
- ClipForge and Quik Clip had no license file found by the repository-tree filename audit. Their source is treated as all-rights-reserved for reuse purposes.
- No third-party dependency or asset was added to OmniFrame as part of this study.
- OmniFrame's ruler implementation was independently written around generic time/scale mathematics.
