# Transition asset sources

All downloaded source models/materials used by this pack are CC0 1.0. Source file sizes and hashes are recorded in `research/transition-assets/source-manifest.json`; packed editable conversions are in `assets-source/transition-pack/`.

| Runtime asset | Original author and source | Modifications |
|---|---|---|
| `tv_crt_knobs_ph` | [Gabriel Radić — Television 01, Poly Haven](https://polyhaven.com/a/Television_01) | Normalized orientation/origin; added an independent live-video display surface. Original 1k PBR body textures retained. |
| `tv_crt_silver_ph` | [Benny Weimer — Television 02, Poly Haven](https://polyhaven.com/a/television_02) | Normalized orientation/origin; added a live-video display. Original 1k PBR body textures retained. |
| `payphone_ph` | [UM JOORIN — Korean Public Payphone 01, Poly Haven](https://polyhaven.com/a/korean_public_payphone_01) | Normalized and decimated to 18% of original faces; original 1k PBR textures retained. |
| `arrow_oga` | [Savino — Arrow symbols, OpenGameArt](https://opengameart.org/content/arrow-symbols) | Uses `arrow1.obj`; normalized and given an original gold PBR material. Source geometry has no textures. |
| `bullet_shell_oga` | [AlexanderZotov — 3D Low Poly Pistol With Bullet Shell, OpenGameArt](https://opengameart.org/content/3d-low-poly-pistol-with-bullet-shell) | Only `bulletShell.fbx` is included, not the pistol. Reoriented and normalized; original colors retained with metallic shading. |
| `concrete_shards_ph` | [Dimitrios Savva — Cracked Concrete, Poly Haven](https://polyhaven.com/a/cracked_concrete) | Material applied to 35 original deterministic Voronoi prisms by OmniFrame. Separate full-image UV fronts carry live outgoing video. |
