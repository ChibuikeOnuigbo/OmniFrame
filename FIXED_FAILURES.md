# OmniFrame Fixed Failures Registry (`FIXED_FAILURES.md`)

This register records permanent post-mortem entries for defects discovered, analyzed, and resolved across OmniFrame's architectural subsystems.

| Failure ID | Subsystem | Severity | Root Cause | Resolution | Verification Test |
|---|---|---|---|---|---|
| F-0001 | Timeline Data Model | High | Clip positions stored as relative coordinates prone to rounding drift during zoom. | Refactored data model to invariant temporal intervals: rational seconds (`start`, `duration`, `trackId`) converted to view pixels via dynamic `pixelsPerSecond`. | `qa/timeline-rebuild-e2e.mjs` |
| F-0002 | Track Hierarchy | High | Hardcoded single-track video container prevented NLE multi-track vertical stacking and picture-in-picture. | Implemented dynamic track model with track objects (`Track { id, name, kind, visible, locked }`), track insertion above/below, and track-aware spatial compositing. | `qa/timeline-rebuild-e2e.mjs` |
| F-0003 | Transitions | Critical | Transitions were simulated via ad-hoc clip CSS opacity classes rather than discrete objects. | Designed and implemented first-class `Transition` entity (`fromClipId`, `toClipId`, `type`, `startTime`, `duration`, `alignment`) with dedicated timeline rendering and trim handles. | `qa/timeline-rebuild-e2e.mjs` |
| F-0004 | Context Menus | Medium | Context menu events intercepted in capture phase defaulted unhandled elements to `EMPTY_EDITOR`. | Extended context menu resolver in `src/Studio.tsx` to detect `[data-testid="timeline-transition"]` and expose transition type presets and duration controls. | `qa/timeline-rebuild-e2e.mjs` |
| F-0005 | Export Pipeline | High | Export button lacked standard QA `data-testid="export-video-btn"` attribute, causing automated E2E selector timeout. | Added explicit `data-testid="export-video-btn"` to TopBar download button. | `qa/timeline-rebuild-e2e.mjs` |
| F-0006 | Automated Testing | High | Editor Zustand store unexposed on `window.__omniframe_store`, impeding automated assertion of transition state changes. | Exposed `(window as any).__omniframe_store = useEditor` in `src/store.ts`. | `qa/timeline-rebuild-e2e.mjs` |
| F-0007 | OpenCV Environment | Medium | Sandbox lacked `opencv-python-headless` package for video frame decoding during test execution. | Installed `opencv-python-headless` and `numpy` via pip with system package override. | `qa/timeline-rebuild-e2e.mjs` |
| F-0008 | Playwright Chromium | High | Sparticuz Chromium runtime missing uncompressed shared library binaries (`libnspr4.so`). | Added `await inflate(...)` and runtime `LD_LIBRARY_PATH` injection prior to browser launch. | `qa/timeline-rebuild-e2e.mjs` |
| F-0009 | Timeline Ruler | Medium | Ruler ticks overlapped and created visual noise at extreme zoom levels. | Implemented adaptive ruler interval algorithm switching between minute, second, half-second, and frame ticks. | `qa/timeline-ruler-e2e.mjs` |
| F-0010 | Media Library Ingestion | Medium | Audio files lacked duration extraction when metadata loading was delayed. | Implemented `AudioContext.decodeAudioData` fallback to reliably compute exact duration in seconds. | `qa/media-library-e2e.mjs` |
| F-0011 | Timeline Split Tool | High | Splitting at playhead failed when playhead was within 0.05s of clip boundary. | Added boundary guard tolerance preventing degenerate 0-second slices. | `qa/stress-e2e.mjs` |
| F-0012 | Right Panel Collapsibility | Low | Inspector panel toggle caused canvas reflow jump when snapping back into view. | Added CSS transition easing and `ResizeObserver` listener on preview canvas container. | `qa/stress-e2e.mjs` |
| F-0013 | Audio Waveform Caching | Medium | Re-generating peaks on every scrub caused noticeable UI thread stuttering. | Implemented persistent 256-point peak arrays in clip metadata, computed once on ingest. | `qa/audio-waveform-e2e.mjs` |
| F-0014 | Video Export Format | High | Canvas `MediaRecorder` crashed on unsupported codec combinations across different browser platforms. | Added MIME type negotiation falling back gracefully between `video/webm;codecs=vp9`, `video/webm;codecs=vp8`, and standard `video/webm`. | `src/lib/export.ts` |
| F-0015 | Settings Modal Dismissal | Low | Clicking inside settings popup backdrop triggered unintended background timeline seek. | Added backdrop `stopPropagation` and modal overlay capture shield. | `qa/reports/settings-popup-tests.md` |
| F-0016 | Transition Rendering in Export | High | Canvas export loop only drew individual clips without blending overlapping transitions. | Integrated shader/canvas transition blending loop into `src/lib/export.ts` rendering cross dissolves, dips, and wipes frame-by-frame. | `qa/timeline-rebuild-e2e.mjs` |
| F-0017 | Drawing UI Component Typing | Medium | `DrawingPanel` and `DrawingToolbar` tool icon typing declared as `React.FC<{ size?: number }>` conflicted with `LucideIcon` ForwardRef typing. | Updated tool definition type to `icon: LucideIcon` imported directly from `lucide-react`. | `qa/drawing-layout-e2e.mjs` |
| F-0018 | Left Dock Drawer Pointer Interception | Medium | Exiting focus mode left drawer collapsed, causing automated click on `add-paint-layer-btn` to be intercepted by adjacent preview viewport during CSS width animation. | Added explicit store drawer expansion (`setLeftOpen(true)`) and 400ms transition stabilization delay before pointer dispatch. | `qa/drawing-layout-e2e.mjs` |
| F-0019 | Layer Mask Conversion Fallback | High | `convertSelectionToMask` failed to generate mask data URL if `activeSelection.maskDataUrl` had not been pre-rendered during initial drag. | Integrated `createSelectionMask(sel, 1920, 1080)` inside `convertSelectionToMask` so any active rectangle, ellipse, or lasso selection immediately rasterizes into a crisp PNG mask before clearing selection. | `qa/layout-selection-mask-e2e.mjs` |
| F-0020 | Custom Workspace LocalStorage Key | Medium | Inconsistent localStorage key between test runner (`omniframe-custom-workspaces`) and store implementation (`omniframe.customWorkspaces`). | Unified key naming to `omniframe.customWorkspaces` with error handling and fallback parsing. | `qa/layout-selection-mask-e2e.mjs` |
| F-0021 | Layout Modal Tab TestIDs | Low | Test automation expected pluralized tab IDs (`tab-custom-workspaces`, `tab-focus-modes`) while modal used concise testids (`tab-custom`, `tab-focus`). | Updated E2E test selectors to target canonical modal tab testids. | `qa/layout-selection-mask-e2e.mjs` |
| F-0022 | Media Ingestion Decoupling | High | Ingesting media files automatically added clips to the timeline, violating the library/timeline separation invariant (Invariant I-10). | Decoupled `importFiles` in `src/store.ts` to add assets strictly to library and load into isolated `SourceMonitor` state. Added explicit "Add to Timeline" controls. | `qa/master-rebuild-e2e.mjs` |
| F-0023 | Same-Track Collision Overlap | Critical | Dragging or inserting clips on the same track allowed spatial overlaps without ripple shifting. | Implemented `resolveSameTrackRipple` algorithm in `src/store.ts` enforcing strict Invariant I-01 non-overlap with downstream ripple cascade. | `qa/master-rebuild-e2e.mjs` |
| F-0024 | Browser Drag Download Artifact | High | Internal clip and asset drag-and-drop operations triggered browser file save / `download.jpg` artifacts. | Implemented domain-typed drag data payloads (`application/x-omniframe-timeline-item`, `application/x-omniframe-asset`) and filtered internal drags from window drop targets. | `qa/master-rebuild-e2e.mjs` |
| F-0025 | Non-Target-Aware Context Menu | Medium | Right-clicking empty track lane displayed generic transition commands and lacked track-level gap operations. | Extended centralized context menu resolver in `src/Studio.tsx` to identify `TRACK_LANE`, exposing "Close Gaps on Track" and track management while blocking transition commands. | `qa/master-rebuild-e2e.mjs` |
| F-0026 | Aspect Ratio Export Synchronization | Critical | Selecting non-standard aspect ratios (e.g. 9:16 portrait) did not propagate to export dimensions, outputting mismatched video. | Synchronized `sequenceSettings` (`targetW`, `targetH`) with export engine and auto-switched monitor mode to `program` during recording. Verified via OpenCV. | `qa/master-rebuild-e2e.mjs` |
| F-0027 | UI Placeholder Stubs Elimination | High | Left dock panels contained planned/future prototype text stubs. | Replaced all stubs with functional components (`TransitionsPanel`, `EffectsPanel`, `TextPanel`, `ThreePanel`) and documented genuine platform boundaries in `UNIMPLEMENTED_INTERNAL.md`. | `qa/master-rebuild-e2e.mjs` |
| F-0028 | Voice Isolation Modal Initial Clip State Sync | High | Opening Voice Isolation Modal from context menu on newly imported clip failed because modal initial state was initialized once on component mount before clip ID was assigned. | Added `React.useEffect` prop synchronization and fallback selector resolving active clip, preventing unselected clip stalls. | `qa/voice-isolation-e2e.mjs` |
| F-0029 | Voice Isolation DSP Phase-Cancellation & Bass Retention | High | Center-channel vocal reduction without multi-band crossover caused bass drum and kick to be canceled along with dialogue. | Implemented Chamberlin SVF 3-band crossover splitting audio into sub-bass (<140Hz mono preservation), vocal formant band (140Hz-7500Hz mid-side phase cancellation), and air band (>7500Hz stereo ambience preservation). | `qa/voice-isolation-e2e.mjs` |
| F-0030 | Timeline Ruler Pointer Capture Swallowing Marker Double-Click | High | Double-clicking timeline marker flags on the timeline ruler failed to open the edit modal in test automation because ruler `onPointerDown` called `setPointerCapture(e.pointerId)`, redirecting all subsequent pointer events and clicks to the ruler scrub handler. | Added `onPointerDown={(e) => e.stopPropagation()}` to `[data-testid="timeline-marker"]`, preventing ruler scrub handler from capturing the pointer when interacting directly with sequence markers. | `qa/marker-audiometer-e2e.mjs` |
| F-0031 | Zero-Level Audio Meter Visibility in DOM-Based Verification | Medium | Playwright's `isVisible()` returned false on `[data-testid="vu-meter-left-bar"]` when no audio was actively playing because the inner LED meter element had `width: 0%`. | Updated test suite to verify DOM mounting and style attribute presence, while checking audio meter container visibility and master volume slider adjustments. | `qa/marker-audiometer-e2e.mjs` |
