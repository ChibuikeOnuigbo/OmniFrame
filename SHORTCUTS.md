# Shortcuts

| Shortcut | Action |
|---|---|
| Space | Play/pause |
| J / K / L | Playback family (K is pause; full transport mapping is a next shell gate) |
| I / O | Mask / Omniframe workspace |
| T | Tracking workspace |
| B | Blade tool |
| V | Select tool |
| M | Marker |
| Left / Right | Previous/next frame |
| Shift + Left/Right | Larger frame step |
| Z | Timeline zoom in |
| H | Pan (reserved for configurable tool) |
| Ctrl/Cmd + Z | Undo |
| Ctrl/Cmd + Shift + Z | Redo |
| Ctrl/Cmd + S | Save `.vxproj` |
| Ctrl/Cmd + Shift + P | Command palette |

Shortcut bindings are project/user configuration data in the project format. The workbench displays the most important editor shortcuts in its timeline footer.
